# Library

Curated music library bundled with the app. Songs and cover images live here;
`manifest.json` is generated by `npm run gen-library`.

## Layout

```
library/
  songs/        # audio files (.mp3, .wav, .ogg, .flac, .m4a, .aac)
  covers/       # cover images, matched by base filename to the song
  manifest.json # generated - do not edit by hand
```

## Adding a song

1. Drop the audio file into `library/songs/`, e.g. `songs/Daft Punk - Aerodynamic.mp3`.
2. Drop a cover image into `library/covers/` with the **same base name**, e.g.
   `covers/Daft Punk - Aerodynamic.jpg` (`.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`).
3. Run `npm run gen-library` (or `npm run build`, which runs it automatically).

The filename is parsed as `Artist - Title`. To override metadata, add a sidecar
JSON file next to the song with the same base name, e.g.
`songs/Daft Punk - Aerodynamic.json`:

```json
{ "title": "Aerodynamic", "artist": "Daft Punk", "album": "Discovery" }
```

If no matching cover image exists, the track is still included with no artwork.
